# 本地测试笔记素材

这组素材包含 10 篇为个人知识管理系统测试而编写的中文 Markdown 笔记。内容为合成示例，不对应真实会议、实验或个人信息，也不依赖飞书。

笔记覆盖研究摘录、会议记录、实验日志、课程笔记、设计 brief、日常记录、概念问答和资料索引等结构，包含标题、正文、表格、列表、代码片段、数字与重复主题，适合检查导入、标签整理、关键词搜索、语义检索和引用展示。
