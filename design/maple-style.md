# 枫叶纸感视觉规范

保持现有页面布局：默认图标导航；笔记本和 AI 对话按需显示可折叠列表栏。

| 用途 | 色值 |
| --- | --- |
| 页面背景 | `#FCFAF7` |
| 图标导航背景 | `#F4EEE8` |
| 列表栏背景 | `#F8F3EE` |
| 卡片 | `#FFFEFC` |
| 主文字 | `#3C322E` |
| 辅助文字 | `#6F625B` |
| 主操作、焦点 | `#965540` |
| 选中背景 | `#EAD9CF` |
| 强调卡片背景 | `#F5E9E1` |
| 边框 | `#E9DFD7` |

标题使用宋体风格，导航、按钮和笔记正文使用清晰的无衬线字体。枫叶色只用于主操作、选中项、焦点和少量关键标记；笔记正文保持深色文字与浅色底面。卡片不使用大面积图片、叶片纹样或厚重阴影。
