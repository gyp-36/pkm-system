操作确认有效期十分钟，确认绑定差异，候选绑定原映射。撤销、另起人类请求、过期、版本变化使待办失效。相同账号/request_id重放原回执，新建默认一篇，明确数量按受限规则处理。原子回滚、并发消息/版本冲突、候选变化、过期清理、重复提交及跨账号确认均使用实际路由和专用PostgreSQL验证。
